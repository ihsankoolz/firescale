# firescale 0.5.1 on the course project

Date: 2026-11-16, 08:51 to 10:50 (UTC+8), on the owner's Windows 11 laptop (Node 22.19.0, npm 10.9.3, Docker 29.1.3, Python 3.13.7 in each service's `.venv`). firescale 0.5.1 from npm (`npx firescale@0.5.1`), with the npx cache cleared first. Course project: `decker757/CS464` at `bc43f27c` (`main`). Its untracked `firescale.config.json`, `image.png`, `cs464_project_export.md` and `verify.log` were left as they were. Nothing in the course project was edited, committed or deleted. Only firescale's own `.firescale` folder there was written. Commands that write files ran in a `git clone` of it in a scratch folder. Nothing in firescale was fixed.

"Course project" means the real folder. "Scratch copy" means the clone, with the untracked `firescale.config.json` and `image.png` copied in.

## Summary

- firescale 0.5.1 installed and ran on the course project. Of the 16 changes the 0.5.1 list expects, 12 were seen (4 only in the scratch copy, 2 only in part) and 4 were not tested.
- The full `verify --jobs 3` took 1h 41m: `verify: FAILED at test in backend/ledger_service, test in frontend`. The ledger_service failures are 3 timing tests (about 45 s against a 5 s limit). **No failure was labelled pre-existing**: the base run spent its 5-minute budget on the 1h 36m ledger step and never ran the 1-minute frontend step.
- The calmer heartbeat, the falling time left and `.firescale/step-times.json` all worked as described.
- The expected `0 of 6 projects ran` could not be shown in the course project: an untracked `verify.log` from an earlier run makes `--affected` run everything. In a clone it came out word for word.
- Tamper guard on 150 real commits: 61 findings, 18 of them false. Two firescale bugs cause all 18: words after the codes of `# noqa:` are read as codes, and the expected-value check fires on a changed failure message or pairs asserts of two different tests.
- `hooks install` writes a `fscale` command that cannot start in this repo, and says nothing about it.
- A real `fix --agent claude` passed for $0.07, and its ledger entry is right. A one-turn limit failed cleanly, and the repo's hooks stayed off. Codex is not installed.
